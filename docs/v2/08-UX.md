# Phase 8 — UX

## 8.1 Principes UX

- **Mobile-first pour le JRI** (terrain), **desktop-dense pour le staff** (compta/rédac).
- **Une action primaire par écran** (bouton principal évident).
- **États explicites** : chargement (skeleton), vide (guidage), erreur (message + action), succès (toast).
- **Résilience réseau** : uploads résumables, sauvegarde de brouillon, retry visible.
- **Accessibilité WCAG 2.1 AA** partout ; **raccourcis clavier** pour les power users staff.
- **Feedback immédiat** : optimistic UI + rollback (déjà sur kanban).

## 8.2 Modèle de navigation

- **Sidebar** (staff) : Dashboard, Planning, Sujets, Médiathèque, JRI, Piges & paiements, Équipements, Dotations, Finance, Rapports, Utilisateurs, Devises, Audit. Lien actif surligné, sections par rôle.
- **Bottom nav** (JRI mobile) : Accueil, Mes sujets, Livrer, Mon matériel, Paiements.
- **Header** : recherche globale, sélecteur langue, sélecteur devise, cloche notifications, menu compte.
- **Breadcrumb** sur les détails (`Sujets / SUJ-2026-0001`).

## 8.3 États standard (tous écrans)

| État | Comportement |
|------|--------------|
| Chargement | skeleton (pas de spinner plein écran) ; conserver la mise en page |
| Vide | illustration + phrase + CTA (« Aucun sujet — Créer un sujet ») |
| Erreur | bandeau rouge + message clair + bouton « Réessayer » |
| Partiel/offline | bannière « Hors ligne — les envois reprendront » |
| Succès | toast 3 s, non bloquant |
| Permission | 403 → page « Accès refusé » avec retour |

## 8.4 Écrans (objectif · hiérarchie · interactions · responsive · états · accessibilité · raccourcis)

### E1 — Login
- **Objectif** : entrer vite et en sécurité. **Hiérarchie** : logo → champs → CTA → liens (mot de passe oublié).
- **Interactions** : validation inline, afficher/masquer mdp, 2FA en 2e étape.
- **Responsive** : carte centrée, plein écran mobile. **États** : erreur identifiants, verrouillage.
- **A11y** : labels associés, focus visible, erreurs annoncées (aria-live). **Raccourcis** : Entrée = soumettre.

### E2 — Dashboard
- **Objectif** : KPI par rôle en un coup d'œil. **Hiérarchie** : bandeau KPI → graphiques → listes à traiter.
- **Interactions** : période, drill-down. **Responsive** : grille 4→2→1 colonnes.
- **États** : skeleton cartes ; vide (« pas encore de données »). **A11y** : graphiques avec table alternative + `aria-label`.
- **Raccourcis** : `g d` (go dashboard), `g s` (sujets)…

### E3 — Planning (kanban/calendrier)
- **Objectif** : piloter les sujets. **Interactions** : drag&drop (optimistic + rollback), bascule kanban/calendrier, filtres.
- **Responsive** : kanban scroll horizontal mobile ; calendrier → liste mobile.
- **A11y** : drag&drop avec **alternative clavier** (déplacer via menu statut). **Raccourcis** : `n` = nouveau sujet.

### E4 — Sujet (détail)
- **Objectif** : produire, livrer, valider. **Hiérarchie** : entête (réf, statut, échéance) → médias → validation → activité.
- **Interactions** : uploader résumable, changer statut, valider/rejeter avec commentaire.
- **États** : upload en cours (progress), rejet (motif visible). **A11y** : ordre de tabulation logique, statut annoncé.

### E5 — Médiathèque
- **Objectif** : retrouver/prévisualiser. **Interactions** : recherche, filtre type, preview, ouvrir. **Responsive** : grille 4→3→2.
- **États** : vignette en génération (placeholder). **A11y** : alt sur vignettes, contrôles vidéo accessibles.

### E6 — Piges & paiements
- **Objectif** : calculer, documenter, payer. **Hiérarchie** : filtres période/exports → table fiches → actions (PDF, Payer).
- **Interactions** : générer masse, calculer, modale de paiement (mode/référence/date), verrouiller période.
- **États** : période verrouillée (badge + actions grisées), fiche payée (immuable). **A11y** : table avec en-têtes scope, montants alignés.

### E7 — JRI (fiche 360°)
- **Objectif** : tout savoir sur un pigiste. **Sections** : profil/tarifs, sujets, revenus, matériel détenu, historique.
- **Interactions** : éditer tarifs/coordonnées (IBAN masqué), inviter. **A11y** : sections en `landmark`.

### E8 — Équipements / détail matériel
- **Objectif** : suivre un actif. **Sections** : infos, QR, maintenance, incidents, dotations. **Interactions** : ticket, incident, scan QR (mobile).

### E9 — Dotations (remise/retour)
- **Objectif** : engager la responsabilité. **Interactions** : photos, **signature tactile**, sélection d'état, calcul de dégradation au retour.
- **Responsive** : pensé mobile (signature au doigt). **États** : non signée (rappel). **A11y** : signature avec alternative (upload image signée) documentée.

### E10 — Finance / Budgets
- **Objectif** : piloter les coûts. **Interactions** : budget vs réalisé, alertes dépassement, export. **A11y** : couleurs + libellés (pas la couleur seule).

### E11 — Paramètres / Admin
- **Objectif** : configurer l'organisation. **Sections** : org, devises, catégories, barème, seuils, utilisateurs, audit.

### E12 — Onboarding (nouveau — Phase 15)
- **Objectif** : activer en < 10 min. **Étapes** : org+devise → inviter équipe → import Excel (JRI/matériel) → 1er sujet. Barre de progression, skippable.

## 8.5 Accessibilité (transversal)

- Contraste ≥ 4,5:1 ; focus visible ; navigation clavier complète ; `aria-live` pour toasts/erreurs ; cibles tactiles ≥ 44px ; pas d'info par couleur seule ; libellés de formulaire explicites ; support lecteur d'écran ; `prefers-reduced-motion`.

## 8.6 Raccourcis clavier (staff)

`?` aide ; `g` + touche (navigation) ; `n` nouveau ; `/` recherche ; `j/k` naviguer une liste ; `Esc` fermer modale ; `⌘/Ctrl+Entrée` soumettre.
